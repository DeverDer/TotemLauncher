# Сервер каталога скинов

Лаунчер показывает скины с сервера, адрес которого записан в `src/app-config.json` (`skinsApi`). Пока адрес пустой, работает встроенный стартовый набор (16 скинов), а счётчик скачиваний ведётся только на этом компьютере.

## Запуск
```
node skin-server/server.js            # http://127.0.0.1:8787, данные в skin-server/data
node skin-server/add.js skin.png "Название" "Автор" slim "Описание"
```
Лаунчер принимает только **https**-адрес, поэтому выставляйте сервер через nginx/Caddy/хостинг с сертификатом, затем при сборке: `TOTEM_SKINS_API=https://skins.example.com npm run dist`.

## Протокол
| Запрос | Ответ |
|---|---|
| `GET /skins` | `{ "skins": [{ "id", "name", "author", "created" (ISO), "downloads", "model" ("classic"/"slim"), "desc" }] }` |
| `GET /skins/<id>.png` | PNG 64×64 до 1 МБ |
| `POST /skins/<id>/download` | `{ "downloads": число }` — увеличить счётчик (сервер учитывает одного человека раз в час) |

`id` — только латиница, цифры, `_` и `-`, до 40 символов. Любой другой сервер с таким же протоколом тоже подойдёт.
